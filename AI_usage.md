##AI usage

Neste documento, relato três exemplos nos quais tive que corrigir a AI ao longo deste trabalho. 

Estes 3 exemplos encontram-se no ficheiro **correction_prompts.excalidraw**

1. Avanço demasiado rápido
O Astra foi demasiado "proativo". Conforme mostrei na reunião antes da entrega, este tentou logo fazer one-shot à app depois do prompt inicial. Como tal, tive que fazer aquele primeiro prompt, de modo a pedir-lhe que desenvolvêssemos a app em conjunto, passo a passo, para poder aprender e validar os seus outputs.

2. Frontend muito pouco apelativo esteticamente
A primeira tentativa de frontend (para além de me rebentar os usage limits!) foi muito pouco apelativo visualmente. Tinha também implementado o jogo, apesar de eu ter anteriormente explicitado que este deveria ficar para o fim. Como tal, utilizei outro prompt para reorientar o modelo.

3. Outra instrução para refinar o frontend
A segunda tentativa de frontend correu melhor, mas continuava a redirecionar o utilizador para a aquela pagina inicial atabalhoada. Instruí o modelo para que criasse uma pagina em especifico para cada funcionalidade. Resultou muito bem, e a estetica resultante foi o resultado final.

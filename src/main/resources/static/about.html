SOBRE O PROJETO

Um lugar para
colecionar histórias.

MovieUniverse Hub junta descoberta de filmes, playlists pessoais e avaliações num só lugar.

Como funciona

Pesquisa filmes, guarda-os nas tuas playlists e dá-lhes uma nota de 1 a 10. A nota combinada considera os votos reais da TMDB e os votos locais, moderados por uma referência de 6,0 com peso 100. Essa referência não representa votos reais.

Compara duas playlists para ver as suas médias, a cobertura das notas e os filmes em comum. O jogo usa filmes das tuas playlists ativas e guarda o teu melhor resultado localmente.

Dados e atribuição

Os metadados e cartazes dos filmes são fornecidos pela TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB.

Para quem desenvolve

A referência da API e o ficheiro OpenAPI estão disponíveis após iniciar sessão.

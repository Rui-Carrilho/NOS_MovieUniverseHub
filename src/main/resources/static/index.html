      SOBRE O PROJETO

      Feito para colecionar histórias.

      MovieUniverse Hub é um projeto local de descoberta de filmes e organização de playlists. As notas combinadas juntam votos da TMDB e dos perfis locais, com uma referência de 6,0 e peso 100 para moderar resultados com poucos votos. Esse peso não representa votos reais.

      This product uses the TMDB API but is not endorsed or certified by TMDB.
